# Changelog

All notable changes to the RecSys.AI SDK are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial SDK implementations for Python, TypeScript, Go, Dart, .NET, Java, Kotlin, PHP, Ruby, Rust, and Swift.
- Four universal methods across all SDKs: `similar`, `popular`, `upsert`, `ping`.
- Typed error classes for 401, 404, 422, 429, and 5xx responses.
- GitHub Actions CI/CD workflows for automated publishing to all 11 package registries.
- MkDocs Material documentation site deployed to GitHub Pages.
